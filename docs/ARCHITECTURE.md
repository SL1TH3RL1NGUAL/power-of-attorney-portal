# Architecture Rules for POA/NDA Portal

## POA Activation Requirements
The Power of Attorney (POA) is only usable after the member receives a green-light approval.

## Prerequisites
- NDA must be accepted.
- Vinculum-member status must be approved.
- Green-light status must be approved by an admin or reviewer.

## Logging Requirements
All uses of POA must be logged to the activity feed, including:
- Timestamp
- User ID
- Action performed
- Reviewer/admin involved (if applicable).
